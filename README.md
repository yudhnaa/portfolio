## Project Structure & Architecture

The project is structured with a modular component architecture for maintainability, while compiling into static distribution files for zero-friction GitHub Pages hosting:

```
portfolio/
├── src/
│   ├── template.html              # Base HTML layout shell (head, metadata, noise overlay)
│   └── components/                # Independent section partials
│       ├── header.html            # Navigation bar, brand logo, mobile menu
│       ├── hero.html              # Hero presentation, avatar, resume trigger button
│       ├── topology.html          # Interactive System Topology & stack mode filter
│       ├── experience.html        # Work experience & education milestones
│       ├── skills.html            # Core competencies & technical skill matrices
│       ├── projects.html          # 6 enterprise featured project cards & metrics
│       ├── contact.html           # Contact channels & footer copyright
│       └── resume-modal.html      # Dual-iframe Google Drive resume viewer modal
│
├── static/
│   ├── js/                        # Modular JavaScript source code (ES Modules)
│   │   ├── main.js                # Application entry point
│   │   ├── resume-modal.js        # Resume modal management & instant dual-frame toggle
│   │   ├── topology.js            # HTML5 Canvas distributed network physics simulation
│   │   ├── navigation.js          # Mobile menu, smooth scrolling, keyboard shortcuts
│   │   ├── projects.js            # Horizontal carousel scrolling controller
│   │   └── tailwind.config.js     # Tailwind CDN theme palette & font configurations
│   ├── script.js                  # Production bundled JavaScript (generated by build.js)
│   ├── styles.css                 # Custom styling, transitions, and animations
│   └── img/                       # Images, avatars, and icons
│
├── build.js                       # Zero-dependency compilation script (Node.js)
├── watch.js                       # Auto-rebuilding file watcher for local development
├── package.json                   # Project metadata and build scripts
└── index.html                     # Compiled production HTML served by GitHub Pages
```

## Development & Build Workflow

### 1. How to Edit Code

- **To update content / UI**: Edit the corresponding component in `src/components/` (e.g., `projects.html`, `hero.html`, `skills.html`).
- **To update logic / interactivity**: Edit the corresponding module in `static/js/` (e.g., `resume-modal.js`, `topology.js`, `navigation.js`).

### 2. Building Assets

Run the zero-dependency build script (uses native Node.js, no external npm packages required):

```bash
# Build index.html and static/script.js
npm run build
# Or directly:
node build.js
```

During active development, run the file watcher to automatically recompile on save:

```bash
npm run watch
# Or directly:
node watch.js
```

### 3. Local Preview

You can preview the portfolio in any of the following ways:
- **Direct file opening**: Double-click `index.html` in your file explorer. (The bundled `static/script.js` avoids browser `file://` CORS restrictions).
- **HTTP server**:
  ```bash
  python3 -m http.server 8000
  ```
  Then open `http://localhost:8000`.

## Deployment (GitHub Pages)

Deployment to **GitHub Pages** is fully automated and requires no special CI/CD build configuration on GitHub:

1. Build your assets locally:
   ```bash
   npm run build
   ```
2. Commit and push your changes to `main`:
   ```bash
   git add .
   git commit -m "feat: update portfolio content"
   git push origin main
   ```
3. GitHub Pages automatically serves the compiled `index.html` and `static/` assets directly from the root of the `main` branch at [portfolio.yudhna.id.vn](https://portfolio.yudhna.id.vn).
